# 가이드 스크린샷 넣는 곳 (Guide screenshots)

이 폴더(`site/guide/images/`)에 아래 파일명으로 PNG를 넣으면, 가이드에서 해당 위치의 안내 박스가
자동으로 사라지고 이미지가 표시됩니다. (가이드 HTML의 `onerror` 폴백)

> 온라인 가이드는 이 폴더를 그대로 씁니다.
> **오프라인(설치본)** 가이드에도 같은 이미지를 쓰려면 동일 파일을 `src-tauri/resources/guide/images/`에도
> 넣고 다시 빌드해야 합니다. (원하면 개발 쪽에서 빌드 시 자동 복사하도록 연결해 드립니다.)
