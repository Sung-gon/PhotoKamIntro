사용 설명서

내 PC의 사진·동영상을 빠르게 찾고, 고르고, 정리하는 로컬 인덱서

시작하기 화면 구성 검색·필터 별점·플래그·선택 크게 보기 동영상 회전·편집·폴더 스캔·Jobs 설정 단축키 FAQ

🚀 시작하기

photoKam은 폴더를 "라이브러리"로 등록해 색인(스캔)한 뒤, 갤러리에서 즉시 탐색합니다. 모든 데이터는 내 PC에만 저장됩니다.

1. 라이브러리 추가

  • 라이브러리 화면에서 사진/동영상이 든 최상위 폴더를 추가합니다(하위 폴더까지 색인).
  • 여러 폴더(예: 외장하드)도 함께 등록할 수 있습니다.

2. 스캔(색인)

  • 추가하면 썸네일·EXIF·메타데이터를 색인합니다. 처음 한 번은 양에 따라 시간이 걸립니다.
  • 설정에서 시작 시 자동 스캔을 켜면, 앱을 닫은 동안 바뀐 파일을 다음 실행에서 자동 반영합니다.
💡 갤러리가 첫 화면입니다. 라이브러리/Jobs/설정은 하단 내비게이션에 있습니다.

🗂 화면 구성

  • 갤러리: 전체 사진/동영상을 가상 스크롤로 훑습니다(수십만 장도 매끄럽게). 검색은 갤러리 안의 토글 패널입니다.
  • 크게 보기: 한 장을 크게 보고 줌/팬, 하단 필름스트립으로 앞뒤 이동.
  • 비교: 2~4장을 나란히(4장=2×2), 줌/팬이 동시 적용.
  • 상세 패널: 오른쪽 EXIF·파일 정보. 📌 핀으로 고정하면 선택이 풀려도 유지됩니다.
  • Jobs: 인덱싱 오류 관리.
  • 설정: 표시/라이브러리/프로그램 그룹.

🔎 검색·필터

갤러리 상단의 검색 패널을 토글해 EXIF 기반으로 좁힙니다.

  • 카메라·렌즈 다중선택: 콤보박스 안 체크박스로 여러 기종 동시 선택.
  • 범위: ISO·조리개·초점거리 최소~최대, 촬영일 from~to.
  • 별점·플래그: 최소 별점, 채택/탈락 필터.
  • 정렬: 촬영일·파일명·가져온 순·별점.
  • 여러 카메라를 함께 검색하면 셀 좌상단에 기종명 컬러 라벨이 표시됩니다.
  • 타임라인 라벨이 현재 보이는 영역의 시작~끝 촬영일을 보여줍니다.

★ 별점·플래그·선택

  • 별점 0~5, 플래그 채택(Pick)/탈락(Reject). 셀과 크게 보기에서 매길 수 있습니다.
  • 숫자 키로 별점, 단축키로 플래그(아래 단축키 표).
  • 다중 선택: 클릭, Ctrl+클릭(추가), Shift+클릭(범위), 빈 곳 드래그(러버밴드).
  • 선택 바에서 비교·회전·휴지통 삭제를 한 번에.
💡 삭제는 OS 휴지통으로 보내 복구할 수 있습니다.

🖼 크게 보기

  • 휠로 확대/축소, 드래그로 이동, 더블클릭으로 맞춤↔확대.
  • 하단 필름스트립으로 같은 폴더 사진을 빠르게 넘김(← →).
  • 과노출(제브라) 경고: ▩ 버튼으로 날아간 흰 영역에 빗금 표시. 버튼 옆에 클리핑 비율(%)이 같이 보입니다.

🎞 동영상

  • mp4/mov/m4v 등은 즉시 재생. 자체 플레이어로 재생/탐색/볼륨/배속/전체화면.
  • 자동 변환 재생: PCM 오디오 mov, HEVC, avi·m2ts·wmv·3gp 등 웹뷰가 못 푸는 파일은 재생용 mp4로 자동 변환합니다(처음 한 번 "준비 중", 이후 캐시).
  • FFmpeg이 내장되어 별도 설치가 필요 없습니다.
⚠️ 일부 mov(올림푸스 등)는 영상은 되지만 오디오가 PCM이라 변환해야 소리가 납니다.

↻ 회전·편집·폴더 열기

  • 사진 회전: 90° 시계방향, 원본에 반영(EXIF 보존).
  • 동영상 회전: mp4/mov/m4v/3gp는 무손실(메타데이터), wmv는 재인코딩. 크게 보기/상세에서 미리보기 후 "적용".
  • 수정하기(✎): 원본을 외부 편집기(설정에서 지정한 포토샵·영상툴) 또는 OS 기본 프로그램으로 엽니다.
  • 폴더 열기: 사진/동영상을 우클릭 → 폴더 열기(탐색기에서 파일 선택). 크게 보기에서 우클릭해도 됩니다.

🛠 스캔·Jobs

  • 오류가 나도 전체 스캔은 멈추지 않고, 실패 항목만 Jobs에 기록됩니다.
  • 오류 항목만 재시도 / 전체 라이브러리 재스캔.
  • 오류 행을 폴더 열기로 확인하거나, 선택 삭제 / 전체 삭제로 로그를 정리할 수 있습니다(파일은 그대로).

⚙️ 설정

표시

  • 테마(다크/라이트), 밀도, 썸네일 크기.
  • 갤러리 스크롤 — 미리 그리기 범위(낮음/보통/높음): 낮을수록 빠른 스크롤 시 CPU/GPU 튐과 다른 영상 끊김이 줄어듭니다. 부드러운 스크롤 최적화: 화면 밖 썸네일 렌더 생략 + 비동기 디코딩.
  • 크게 보기 앞뒤 미리 불러오기.

라이브러리

  • 시작 시 자동 스캔, 제외 폴더, 인덱싱 동시 작업 수, ffmpeg 폴더, 저장소/캐시 관리.

프로그램

  • 사진/동영상 편집기 지정, 정보(버전).

❓ 자주 묻는 질문

동영상이 안 보여요

mp4/mov는 보통 바로 재생됩니다. avi·m2ts·wmv 등이나 PCM 오디오 mov는 처음 열 때 변환이 필요해 잠깐 "준비 중"이 뜬 뒤 재생됩니다. 변환본은 캐시되어 다음부터 빠릅니다.

mov는 화면은 나오는데 소리가 없어요

해당 mov의 오디오가 PCM이라 웹뷰가 직접 못 풉니다. 변환이 끝나면 소리까지 정상 재생됩니다.

스크롤하면 다른 프로그램(유튜브 등)이 잠깐 끊겨요

스크롤 순간 썸네일 디코드/합성으로 GPU·CPU를 짧게 많이 씁니다. 설정 > 표시 > 갤러리 스크롤에서 미리 그리기 범위=낮음으로 줄이면 완화됩니다.

내 데이터는 어디로 가나요

어디로도 가지 않습니다. 색인·캐시·원본 모두 내 PC에만 있고, 외부 전송이 없습니다.
