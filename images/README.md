# 스크린샷 이미지

소개 페이지(`../index.html`)가 참조하는 캡처 이미지를 이 폴더에 아래 **파일명 그대로** 넣으면 자동으로 표시됩니다.
넣기 전에는 페이지에 `[..이미지삽입] images/파일명` 자리표시가 보입니다.

| 파일명 | 화면 | 권장 캡처 |
|---|---|---|
| `01-gallery.png` | 갤러리 | 사진이 채워진 그리드 메인 (히어로에도 사용) |
| `02-search.png` | 검색 | 🔎 검색 패널을 펼친 상태 |
| `03-lightbox.png` | 크게 보기 | 사진 1장 + 하단 필름스트립 + 별점 바 |
| `04-detail.png` | 상세 정보 | 우측 상세 패널(EXIF·별점·플래그) |
| `05-library.png` | 라이브러리 | 폴더 목록·스캔 화면 |
| `06-settings.png` | 설정 | 설정 화면 일부 |

권장: 가로 1600px 내외 PNG. 16:10 ~ 16:9 비율이 보기 좋습니다.
